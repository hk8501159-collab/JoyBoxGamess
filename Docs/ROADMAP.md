# Prototype roadmap

## 1. Greybox foundation

- Create and save `Content/Maps/MainMap`.
- Confirm the project compiles and the third-person controls feel right.
- Shape the road, city edge, village lane, and a small landmark from placeholder geometry.

## 2. Exploration slice

- Add collision-safe paths, simple interaction prompts, and a checkpoint.
- Replace a few placeholder structures with original modular environment pieces.
- Set a clear visual distinction between city and village.

## 3. One vehicle and one mission

- Add one drivable vehicle with enter/exit interaction.
- Add one short mission that uses a city-to-village trip.
- Save mission completion and player checkpoints.

## 4. Android pass

- Add touch movement, camera, jump, and interaction controls.
- Profile memory, frame time, draw calls, and loading on the agreed minimum device.
- Reduce the test area or asset complexity where measurements require it.

## 5. Expand deliberately

- Add content only after the first route and mission work on both target platforms.
- Keep a small test build playable at each milestone.
